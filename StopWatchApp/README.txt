A simple and user-friendly WinForm stopwatch app built with c#
Users can start, stop, reset and lap their times all while being saved using JSON files.

This project was created to practice core C# skills including GUI, File handling, control flow, and building menu-driven applications

-----------The Features Include-----------

Stop the timer

Start the Timer

Lap your time

Reset your time

Save and Load your times

-----------How to Run-----------

Navigate into the StopWatchApp folder

Then go to bin --> debug --> net7.0-windows

and run the StopWatchApp.exe
